StreamingWAM

Streaming World Action Modeling via
Chunk-Wise Staircase Flow Matching

Abstract

World action models can generate expressive action chunks, but repeatedly restarting the denoising process introduces latency and breaks continuity between successive chunks. StreamingWAM instead maintains a persistent action buffer and advances a staircase of noise levels across control cycles. Each new observation triggers one steady-state update, while a clean action prefix and dense visual history preserve temporal context. This produces low-latency, continuous control without discarding the remaining plan at every replan.

Method

StreamingWAM amortizes action generation over time. Three components turn chunk-wise diffusion into a rolling control process.

Staircase noise schedule

Future action blocks occupy staggered noise levels, so each planning call performs one denoising update.

Clean action prefix

Recently executed actions condition the next prediction and reduce discontinuities at chunk boundaries.

Dense visual history

Recent observations provide the temporal context needed to react to moving objects and scene changes.
