# Release scope

The first public release covers only LIBERO-Plus training and inference.

Included:

- the model and data pipeline needed by the LIBERO-Plus configuration;
- the staircase future-action loss and rolling inference path;
- exact training and evaluation configs;
- the evaluation manifest and normalization statistics.

Deferred:

- real-robot collection, deployment, and evaluation code;
- RoboTwin-specific training and evaluation assets;
- model weights and robot datasets.

The deferred items are absent rather than represented by placeholders.
